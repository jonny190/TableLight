# TableLight PCB - PCBWay fabrication package

Everything in this folder is generated by `../build_board.py` from the KiCad board
`../kicad/tablelight.kicad_pcb`. Upload `tablelight-gerbers.zip` to PCBWay; if you also want them to
assemble the SMD side, add `tablelight-bom.csv` and `tablelight-cpl.csv`.

| File | Use |
|---|---|
| `tablelight-gerbers.zip` | Gerber RS-274X (copper, mask, paste, silk, outline) + Excellon drill + drill map PDF |
| `tablelight-bom.csv` | PCBWay assembly BOM (Designator, Qty, MPN, Description, Package, SMD/THT) |
| `tablelight-cpl.csv` | pick-and-place (Designator, Mid X, Mid Y, Layer, Rotation), top side, mm |
| `../kicad/tablelight.kicad_pcb` | the board itself (KiCad 7) for any edits |
| `../kicad/drc_report.txt` | DRC report of the exact board that was exported |

## Assembly (optional, "PCB Assembly" quote)

* Assembly side: **top only** (single-sided SMD). The board has no components on the bottom.
* Supply parts: **turnkey** with the BOM. Fill in the *Manufacturer* column or let PCBWay source
  equivalents; the *Mfg Part #* column gives a known-good part for each line.
* THT parts (BT1, BT2, J2-J5, SW1) can be left off the assembly order and hand soldered in 20 minutes.
  The USB-C receptacle (J1) is SMD with through-hole shield legs: PCBWay handles it as SMD.
* The 18650 holders (Keystone 1042) are SMD-mount and heavy; if you include them in the assembly,
  ask for them to be soldered last.
* Pad 1 of each holder is wired as the **positive** terminal (silk "+" marks at the −X end of the board).
  Confirm that orientation against the holder body before installing cells.

## What was checked before export

* KiCad DRC on the exported board (report in `../kicad/drc_report.txt`): zero clearance, edge,
  hole, courtyard and unconnected errors. Remaining entries are silkscreen cosmetics and "footprint
  not in library table" notices (the board is generated without a project library table).
* Net list against `../tablelight_netlist.py` (same object graph feeds both the netlist and the board).
* Antenna keep-out: no copper on either layer under the ESP32 module antenna, module edge at the board edge.
* Screw-head keep-outs: no copper on the component side within 4 mm of the four M3 mounting holes.
* Mechanical positions of J1 (USB-C), SW1 and D3/D4 match the openings in `cad/tablelight.py`.

## What you should still look at before paying

This board was placed by hand and routed by an autorouter (freerouting), then checked by DRC. That
makes it manufacturable, not necessarily pretty. Ten minutes in KiCad are well spent on:

1. Open `../kicad/tablelight.kicad_pcb`, press `B` to refill zones, run DRC once more.
2. Look at the charger area (U2, D1, Q2): make sure the GND pour connects to the TP4056 exposed pad
   with several vias (thermal relief spokes are set to 0.4 mm).
3. The boost inductor loop (L1 - U4 pin 1 - D2): keep the autorouted tracks short; if freerouting
   detoured, drag them.
4. Confirm the USB-C receptacle's silkscreen edge line sits just outside the board edge (face 1 mm past
   the edge is intentional so the plug reaches through the 2.5 mm wall).
